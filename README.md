## 📌 Description
Unsupervised machine learning pipeline running Recency, Frequency, Monetary (RFM) scoring and K-Means persona clustering.

## 🛠️ Architecture & Highlights
- **Production Modular Design**: Standard clean code layout with runnable script entry point.
- **Extensible**: Ready for cloud deployment, Docker microservice wrapping, or educational analysis.

## 📦 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparkx313/ml-customer-segmentation-rfm.git
   cd ml-customer-segmentation-rfm
   ```

2. **Run the entry point**:
   ```bash
   python rfm_segmentation.py
   ```
